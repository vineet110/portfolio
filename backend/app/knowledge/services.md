# Services

## What we offer
We make websites and apps. The studio offers exactly three services:

- Websites
- Mobile Apps
- UI/UX Design

There are no other services right now. Future services may be added later
as the studio grows, but they are not part of the current offering.

## Websites
Business websites, startup websites, custom websites, and full web
applications — including AI-integrated websites and web apps when AI
genuinely helps the product. This covers everything from a landing page to
a complete web application, built fast, built clean, and built to work on
every screen.

## Mobile Apps
Custom mobile application design and development for iOS and Android,
designed and built around how people actually use a phone — not a desktop
site shrunk down.

## UI/UX Design
User experience and interface design for websites, web apps, and mobile
products — research, flows, and interfaces that give an idea a clear shape
before a single line of code is written.

## How AI fits in
AI is not a separate service. Where it genuinely helps — for example an
AI-integrated feature inside a website or web app — it's built in as part
of the Websites service, not sold as its own category.
